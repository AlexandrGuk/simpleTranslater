# simpleTranslater

Расширение для Chrome и Firefox. Выделенный текст на латинице переводится на русский.

Сервис выбирается в окне расширения и запоминается:

- Google и Яндекс запрашиваются напрямую из браузера.
- Премиум ходит на `https://alxgk.site/translate/premium`. Сейчас там тот же машинный перевод, место оставлено под ИИ.

Загрузка без магазина: Chrome — «Расширения» → режим разработчика → «Загрузить распакованное». Firefox — `about:debugging` → «Этот Firefox» → «Временное расширение».
