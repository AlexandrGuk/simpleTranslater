# simpleTranslater

Расширение для Chrome и Firefox. Выделенный текст на латинице переводится на русский через свой сервер.

Сервер: [simple-translate-server](https://github.com/alexandrguk/simple-translate-server). Адрес и токен задаются в настройках расширения. По умолчанию используется `http://5.61.33.30:5000`.

Загрузка без магазина: Chrome — «Расширения» → режим разработчика → «Загрузить распакованное». Firefox — `about:debugging` → «Этот Firefox» → «Временное расширение».
